Vh_Helper_Bot
Телеграм-бот для работы с аккаунтом виртуального хостинга Timeweb через API.

Бот умеет:
    1.Заходить под конкретным аккаунтом через логин и пароль.
    2.Показывает список сайтов.
    3.Показывает список доменов.
    4.Показывает баланс.

Требования для запуска:
    1. Python 3.6 или выше.
    2. Публичный ключ API.
    3. Токен телеграм бота (Можно создать бота и получить ключ у @BotFather).
    4. Отсутствие 2FA на аккаунте.

Структура:
    1. bot.py - обработчик команд.
    2. timeweb_api.py - API ключ.  
    3. storage.py - Хранение токенов и шагов авторизации (SQLite). 
    4. webhook_app.py - flask приложение, принимающее запросы от Telegram.
    5. set_webhook.py - регистрация webhook в Telegram.

Переменные и окружения:
    1. BOT_TOKEN - токен от BotFather.
    2. TIMEWEB_APP_KEY - API ключ Timeweb.
    3. TELEGRAM_API_URL - прокси к Telegram.
    4. WEBHOOK_URL - Адрес webhook.
    5. WEBHOOK_SECRET - Секрет, который Telegram передаёт в заголовке запроса.

Локальный запуск:
    1. Создать и активировать окружение: python -m venv venv.
    Если Win - venv\Scripts\Activate.ps1 Для Linux/macOS - source venv/bin/activate
    2. Установить зависимости: pip install -r requirements.txt .
    3. Скопировать .env.example в .env, заполнить BOT_TOKEN и TIMEWEB_APP_KEY .
    4. Запустить: python bot.py .
Запуск bot.py удаляет webhook. Если бот работает на сервере, после локальных тестов нужно снова выполнить python set_webhook.py.

Пароли не сохраняются. Сохраняется только токен, который выдает API. 

В API не увидел отдельного метода по спискам доменов, по этому собрал домены из поля `domains` в ответе по сайтам.
