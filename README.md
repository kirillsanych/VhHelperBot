Vh_Helper_Bot
Телеграм-бот для работы с аккаунтом виртуального хостинга Timeweb через публичный API.

Бот умеет:
1.Заходить под конкретным аккаунтом через логин и пароль.
2.Показывает список сайтов.
3.Показывает список доменов.
4.Показывает баланс.

Требования для запуска:
1. Python 3.6 или выше.
2. Публичный ключ API.
3. Токен телеграм бота (Можно создать бота и получить ключ у @BotFather).
4. Отсутствие 2FA на аккаунте.

Запуск бота:
1. Клонировать репозиторий и перейти в папку проекта.
2. Создать виртуальное окружение и активировать бота:
Для Linux/MacOS - python -m venv venv && source venv/bin/activate .
Для Win - python -m venv venv потом venv\Scripts\Activate.ps1 .
Установить зависимость - pip install -r requirements.txt .
Скопировать .env.example в .env и указать значения.
Запустить бота - python bot.py .

Какие переменные использовать:
1. BOT_TOKEN - Токен от @BotFather .
2. TIMEWEB_APP_KEY - Ключ API Timeweb .

Проверить бота:
1. Найти бота - @Kirill_VhTestBot .
2. Отправить /start .
3. Нажать "Авторизация", указать логин и пароль. Логин будет отбражен в истории чата, а пароль после ввода сразу удалится.
4. Потыкать "Баланс", "Сайты", "Домены". 

Логин аккаунта - cj653736. Если нужен пароль, то пришлю в ТГ.

Меню и обработчики - bot.py .
Данные клиента Timeweb - timeweb_api.py .
Токен пользователя (SQLite) - storage.py .

Пароли не сохраняются. Сохраняется только токен, который выдает API.
